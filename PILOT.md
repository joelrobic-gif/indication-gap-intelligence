## Objective

Run the ExpandRx engine on **[Partner]'s real molecule portfolio** to surface, rank, and
cost the highest-conviction **indication-expansion** opportunities (approved abroad, open in
**[home market, e.g. Canada]**), and deliver them as committee-ready business cases — proven

## Scope (fixed, time-boxed)

1. Ingest **[Partner]**'s portfolio (molecule list + any internal pipeline notes) behind the
   existing data-adapter.
2. Build a **source-verified slice** for **[1 therapy area, e.g. cardiovascular]** — every
   indication cited to a regulator label or ClinicalTrials.gov NCT.
3. Produce **[N, e.g. 10]** ranked rNPV business-case reports on **[Partner]**'s own assets.
4. Deliver the methodology whitepaper + calibration report alongside.

  sensitivity → recommendation), each citation-backed.
